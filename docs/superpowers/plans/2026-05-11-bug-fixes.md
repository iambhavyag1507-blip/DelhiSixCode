## Task 1: Fix SPA Routing (Critical)

Direct navigation to `/collection`, `/collection/1`, `/contact` returns Netlify's 404 page. The `netlify.toml` redirect rule exists but the `[build]` section is absent, meaning Netlify may not be reading the config at all. A `public/_redirects` file is the most reliable fallback — CRA copies it into `build/` automatically and Netlify processes it first.

**Files:**
- Create: `my-app/public/_redirects`
- Modify: `my-app/netlify.toml`

- [ ] **Step 1: Create `_redirects`**

Create `my-app/public/_redirects` with exactly this content (no trailing newline issues matter here, but keep it a single line):

```
/* /index.html 200
```

- [ ] **Step 2: Add `[build]` section to `netlify.toml`**

Open `my-app/netlify.toml`. Replace the entire file with:

```toml
[build]
  base    = "my-app"
  command = "npm run build"
  publish = "build"

[[headers]]
for = "/images/*"

[headers.values]
Cache-Control = "public, max-age=31536000, immutable"

[[headers]]
for = "/static/*"

[headers.values]
Cache-Control = "public, max-age=31536000, immutable"

[[headers]]
for = "/build/*"

[headers.values]
Cache-Control = "public, max-age=31536000, immutable"

[[headers]]
for = "/*"

[headers.values]
Cache-Control = "public, max-age=3600, must-revalidate"

[[redirects]]
from = "/*"
to   = "/index.html"
status = 200
```

Note: The old file had `Content-Type = "image/webp; charset=utf-8"` under `/images/*` — this is removed here because it was incorrectly declaring JPEGs as WebP (Important bug #4 from the review).

- [ ] **Step 3: Verify `_redirects` is in place**

```bash
cat my-app/public/_redirects
```

Expected output:
```
/* /index.html 200
```

- [ ] **Step 4: Commit**

```bash
git add my-app/public/_redirects my-app/netlify.toml
git commit -m "fix: add _redirects for SPA routing and correct netlify.toml build config"
```
